### 合成匹配（用户: "配方没问题但摆放识别错误/不识别"）——3 个根因
- **maxC 包围盒 bug（真凶）**：`maxC = c` 直接赋值，内层循环 c 每行从 0 开始 → maxC 被每行开头的 c=0 覆盖 → 所有包围盒尺寸/对齐错乱 → 大量配方不识别/识别错。RecipeRegistry.match/consumeMap 全改 `Math.max`。
- **缺旋转**：原版配方支持任意旋转摆放（D4 群）。match 只有镜像 4 种，缺 rot90/rot270 → 横竖摆错位不识别。补 `transforms()` 8 种（含 rot90/rot270 + 组合）。
