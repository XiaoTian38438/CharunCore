# 2026-06-13 工作日志

## 第一轮修改（机制 Bug 修复）
1. **装备同步延迟**：NetworkHandler 0x34 分支添加 `broadcastEquipment()`。
2. **流体物理失效**：FluidEngine 中向下流动与四周蔓延不再互斥，新流体继续 `scheduleFluidTick`。
3. **红石系统缺陷**：
   - 操作者不同步：0x3F 分支恢复 ACK (0x04)。
   - 视觉不连通：添加 `calcWireConnection` / `isRedstoneConnectable` 计算红石线形状。
   - 受体太少：扩展 TNT、动力铁轨、门、音符盒、发射器/投掷器、活塞。

## 第二轮修改（功能增强 + 地形重写）
4. **玩家退出实体不消失**：恢复 `channelInactive` 中的 `entity_destroy` (0x4B) 广播。
5. **地形重写**：
   - Chunk.java `write()` 改为**动态调色盘**：遍历每个 section 的唯一 stateId，自动选择 0-bit 单值或 4~15-bit 调色盘模式，支持 Direct palette (15-bit)。
   - NoiseChunkGenerator 改为**标准超平坦**：1 层 bedrock (-64) + 2 层 dirt (-63~-62) + 1 层 grass_block (-61)。
6. **死亡无法重生**：`handlePlay` 开头添加死亡状态过滤；死亡时设置 `isDead=true`；重生包 ID 修正为 0x50；重生点改为 y=-60。
7. **现代 PvP**：添加攻击冷却（625ms 基础），伤害 = base * (0.2 + 0.8 * 进度)；暴击 1.5x；使用 `hurt_animation` (0x29) + `damage_event` (0x19) 替代旧版 entity_status。
8. **玩家消息**：从 system_chat (0x77) 改为 `profileless_chat` (0x21)，带 sender hoverEvent。
9. **箱子交互**：`isInteractable` 已包含箱子；`handleBlockInteraction` 添加发送 `open_window` (0x39)；添加 `close_window` (0x12 serverbound) 处理。
10. **活塞朝向**：`applyPlacementContext` 添加 piston/sticky_piston/dispenser/dropper/hopper 的 facing。
11. **TNT 爆炸**：RedstoneEngine 中 TNT 激活后延迟 2 秒，移除周围 3x3x3 非基岩/黑曜石方块。
12. **活塞推动（简化）**：`extendPiston` / `retractPiston` 在活塞激活/关闭时生成/移除 `piston_head` 方块，并破坏前方一格可推动方块。
