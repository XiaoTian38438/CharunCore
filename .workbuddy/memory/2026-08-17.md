# 2026-08-17 工作日志

## 插件打包与加载排错（MyPlugin）
- 插件不走 Maven：`mvn package` 报错 "no POM"（目录无 pom.xml）。官方 `docs/PLUGIN_API.md` 规定插件用 `javac -cp target/classes` + `jar cf` 打独立 jar，服务器 URLClassLoader 热加载 `plugins/*.jar`。
- 插件源码从 `src/main/java/com/example/MyPlugin` 挪到 `plugins-src/MyPlugin/`（避免被主项目 `mvn compile` 编进服务器 jar）。新增 `plugins-src/MyPlugin/build.bat` 一键构建。
- **ClassNotFoundException 根因**：`MyPlugin.java` 原 `package com.example.MyPlugin;`，使类真实全名变成 `com.example.MyPlugin.MyPlugin`；而 `plugin.yml` 的 `main: com.example.MyPlugin` 期望「包 com.example + 类 MyPlugin」。defineClass 报 `wrong name: com/example/MyPlugin/MyPlugin`。已改为 `package com.example;`，验证 `Class.forName` 正常加载且 `extends Plugin=true`。
- **Windows 注意**：运行中的服务器会锁死 `plugins/*.jar`，重建前必须停服，否则 `jar cf` 报「另一个程序正在使用此文件」。
