## Bug 修复：`/locate stronghold` NPE 崩溃
- 现象：`StructureSet.loadAll()` 对每个 json 调 `get(id)`，`get` 把 `load()` 的 null 也缓存进 map（strongholds.json 是 `concentric_rings` 放置，`load` 显式 return null）；`resolveStructureSet` 遍历 `all.entrySet()` 时 `en.getValue()` 为 null → `getStructures()` NPE。该 NPE 对**所有** `/locate` 都会触发（loadAll 总会把 strongholds 变 null 项）。
- 修复 1：`StructureSet.get()` 不缓存 null（`if (loaded != null) cache.put(...)`）。
- 修复 2：`resolveStructureSet` 遍历加 `if (ss == null) continue;` 防御。
- 修复 3（核心）：stronghold 用 concentric_rings，结构集无法表示；`/locate` 改为「先 structure2 random_spread 路径，str(onghold) 回退到 `StructureManager.findNearest("stronghold",...)`」。后者复用 `shouldPlace` 同一套数学（seed=WORLD_SEED，spacing=48,sep=12），与 `generateStronghold` 生成器坐标**完全一致**。
- 运行时验证：`findNearest("stronghold",0,0)` = [14,1]，按 shouldPlace 重算得 (14,1) match=true。全量重编 EXIT=0。
