# 生存流程端到端功能审计（YanRong Server 1.21.11）

> 生成日期：2026-08-15
> 视角：假装一位 MC 玩家，从进入服务器一无所有，按生存模式发育到击败末影龙、拿龙蛋+鞘翅，再到红石生电（红石科技）玩家的各种机器。
> 方法：逐里程碑列出**所需功能**并核对代码实现，标注 ✅ 可用 / ⚠️ 部分可用 / ❌ 缺失。
> 说明：本报告基于静态代码核对（本沙箱无法实机运行 Minecraft 客户端）。标 ✅ 表示代码层面逻辑已具备；标 ⚠️/❌ 表示存在偏差或缺失，需实机验证或补实现。
