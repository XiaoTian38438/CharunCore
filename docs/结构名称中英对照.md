## 五、关于“4 个手搓结构”的重要说明（为什么不是 NBT）

`desert_pyramid` / `jungle_pyramid` / `swamp_hut` / `monument` 在原版中确实是**单个 NBT 模板**结构，理论上应直接加载 NBT 即可完美对齐。但经核实：

- 项目本地 `json/minecraft/structure/` 仅有 14 个目录（ancient_city / bastion / end_city / fossil / igloo / nether_fossils / pillager_outpost / ruined_portal / shipwreck / trail_ruins / trial_chambers / underwater_ruin / village / woodland_mansion），**不含这 4 个**。
- 项目所用的反编译 jar（`mapping/remapped_server_1.21.11.jar`）与官方 `server.jar`（实为 Mojang 映射 jar，零 `data/minecraft` 内容）**均不含这 4 个 NBT 模板**。
- 因此当前无法从权威原版源获取这 4 个模板，**未伪造数据**，保持手搓近似并明确标注。

**修复路径（待获取真实模板后一键切换）**：从任意**完整**的 Minecraft 1.21.11 安装（真实 `server.jar` / `client.jar` 内的 `data/minecraft/structures/`，或官方 vanilla datapack）抽取以下文件，gzip 后放入 `json/minecraft/structure/`：

```
desert_pyramid/desert_pyramid.nbt
jungle_pyramid/jungle_pyramid.nbt
swamp_hut/swamp_hut.nbt
monument/monument.nbt
```

随后将 `NonJigsawPlacer` 的 `placeDesertPyramid` / `placeJungleTemple` / `placeSwampHut` / `placeOceanMonument` 改为 `StructureTemplate.load(...).placeInWorld(...)`（与 `placeIgloo` 同模式），即可与其余结构一致地“用原版 NBT 模板”生成。原版这些 NBT 自带战利品表（chests/desert_pyramid 等），无需手动放箱。
